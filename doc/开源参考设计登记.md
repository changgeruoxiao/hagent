## 3. 复用注意

1. **ST 官方原理图**归 ST 版权所有——只作电路处理方式的对照，不可整页复用或照抄布局。
2. **WeAct 仓库为 GPL-3.0**——直接复用其图纸/PCB 源文件会引入 GPL 传染义务；本项目原理图/PCB 由脚本按自有规格书自动生成，仅做参数级对照，不构成其衍生作品。
3. **oshwhub 项目**按平台开源协议（CC 类）在线查看/克隆到嘉立创 EDA，导出需登录，故仅登记链接。
4. **网络备注**：`raw.githubusercontent.com` 在当前网络不可达（Connection reset）；从 GitHub 下载文件走 `api.github.com` 的 Git Blobs 通道（`Accept: application/vnd.github.raw`），已验证可用。
5. Altium 导出的 PDF 用 pypdf 提取不到元件值（矢量图形化），看具体参数需打开 PDF 人工查看。

## 4. 已完成对照项摘要（详见规格书附录 B）

- VDD33_USB → 3.3V 域：官方 Nucleo 板一致 ✓
- VCAP×2 / PDR_ON / BOOT0（电阻+选择器）：官方 Nucleo 板一致 ✓
- LSE 3215 封装 32.768kHz：官方 Nucleo 板一致（NX3215SA）✓
- USB-C 供电 + CC 上下拉 + DFU 下载 + PC13 用户键 + 四层板：WeAct 板一致 ✓
- HSE：Nucleo 用 ST-LINK MCO 馈入（调试器方案），WeAct/本设计用晶振——产品定位不同，本设计选 8MHz 晶振（与 DS12110 Figure 71 典型应用一致）
