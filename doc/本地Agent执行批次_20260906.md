## 3. Experiment B 运行要求

至少跑 3 次独立 Freerouting run。每次必须从同一份 fresh DSN 开始，不允许以上一轮 SES 为输入继续优化。

固定参数：

```text
signal width = 0.20mm
clearance = 0.15mm
via = 0.40/0.20mm
In1 = GND only
In2 = +3V3 + explicit ordinary-GPIO whitelist
critical/semantic nets = F/B only
-mt = 1
```

记录每次：

- `max_passes`
- Freerouting completion marker
- unconnected count
- KiCad DRC error count
- clearance errors count
- via count（若现有脚本可直接获得）
- 总走线长度（若现有脚本可直接获得）
- runtime

不要只记录最好的一次。提交 `min / median / max` 或三次原始结果。
